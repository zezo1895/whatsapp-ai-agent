# وكيل مبيعات واتساب الذكي | WhatsApp AI Outreach Agent 🚀

وكيل مبيعات ذكي مبني بتقنيات الذكاء الاصطناعي (Google Gemini) ومكتبة Baileys لإدارة حملات المبيعات والتسويق الآلي عبر واتساب، واستقبال العملاء، والرد الآلي الذكي من واقع كتالوج وبيانات الشركة، مع نظام استخراج وتنقيب ذكي للعملاء (AI Lead Finder) في محافظات مصر.

---

## 🌟 أبرز مميزات النظام

1. **حملات تسويق ذكية (Cold Outreach مع استئذان مسبق):**
   * إرسال رسائل افتتاحية راقية ومخصصة لكل عميل بنظام استئذان احترافي («متاح أخد من وقتك دقيقة سريعة بخصوص تغليف المكان عندكم؟») بدون حرق المنتجات أو إزعاج العميل.
   * صياغة ذكية بالذكاء الاصطناعي لكل رسالة لتجنب تكرار النصوص وتقليل احتمالية الحظر.
   * التزام صارم بحدود الأمان (Anti-Ban Delays & Batching): فترات تأخير عشوائية من 60 إلى 180 ثانية، مع راحة بين الدفعات.

2. **الرد الآلي الذكي (AI Auto-Reply):**
   * دعم نماذج Google Gemini Flash للرد الفوري واللبق باللهجة المصرية المهذبة («يا فندم»).
   * استخراج وتطابق فوري مع كتالوج الشركة (أكثر من 1350 صنف تعبئة وتغليف وكرتون بمقاساتها وأوزانها).
   * فهم ذكي للطلبات: تحويل أرقام مسؤولي المشتريات (Procurement Referral)، إرسال روابط الكتالوج، وإرسال لوكيشن الفروع والمعارض الرسمية.
   * دعم الرسائل الصوتية والصور مع تأكيد الاستلام الفوري للعميل.

3. **محرك التنقيب واستخراج العملاء (AI Lead Finder):**
   * استخراج وتصنيف مطاعم، كافيهات، حلويات، ومصانع مصرية في مختلف المحافظات.
   * فلتر تحقق صارم (Live WhatsApp Verification) للتأكد من وجود حساب واتساب نشط على الرقم قبل إضافته.
   * حظر التكرار التلقائي لحماية الأرقام التي تم مراسلتها سابقاً.
   * نظام متابعة الأسبوعين (14-Day Re-engagement Pipeline).

4. **لوحة تحكم تفاعلية متكاملة (Web Dashboard):**
   * ربط واتساب عبر مسح كود QR حي مباشرة من المتصفح.
   * رفع واستيراد وتصدير ملفات Excel و CSV.
   * متابعة المحادثات الحية والتدخل اليدوي بضغطة زر.
   * إحصائيات فورية ومؤشرات إرسال وتفاعل حية عبر Socket.IO.

## 🛠️ المتطلبات والتشغيل

### 1. المتطلبات
* **Node.js** (الإصدار 18 أو أحدث)
* حساب **Google Gemini API Key**

### 2. التثبيت والتشغيل
```bash
# استنساخ المشروع
git clone https://github.com/zezo1895/whatsapp-ai-agent.git
cd whatsapp-ai-agent

# تثبيت الحزم
npm install

# إعداد المتغيرات
cp .env.example .env
# قم بإضافة مفتاح GEMINI_API_KEY داخل ملف .env

# تشغيل السيرفر
npm start
```

بعد التشغيل، افتح المتصفح على:
👉 **`http://localhost:3050`**
